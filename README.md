## Описание проекта
Информационная система для автоматизации бизнеса в сфере проката свадебных нарядов. Особенность проекта — изначальное проектирование и внедрение механизмов информационной безопасности для защиты финансовых данных и персональных данных клиентов.

## Функциональные возможности
* **Запись на примерку:** система бронирования времени для клиентов.
* **Каталог нарядов:** просмотр доступных платьев с фильтрацией и поиском.
* **Учет дефектов:** фиксация состояния наряда при выдаче и возврате.
* **Учет залогов:** прием, хранение и возврат денежных залогов.

## Аспекты информационной безопасности
* **Контроль целостности данных о залогах:** защита от несанкционированного изменения финансовых записей задним числом.
* **Авторизация и RBAC:** строгое разграничение прав доступа (Гость, Клиент, Менеджер, Администратор).
* **Защита конфиденциальных данных:** шифрование ПДн и сумм залогов в БД «на лету».
* **Безопасность веб-приложения:** защита от SQL-инъекций (через ORM), XSS и CSRF-атак.

## 🛠️ Технологический стек
* **Backend:** Python, Flask
* **База данных:** PostgreSQL, SQLAlchemy
* **ИБ и криптография:** Flask-Bcrypt, cryptography (Fernet), Flask-WTF
* **Аналитика:** Yandex DataLens (дашборды для анализа)
