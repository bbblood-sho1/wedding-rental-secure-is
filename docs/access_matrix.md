## 1. Описание ролей

В системе выделены **4 роли** в соответствии с принципом наименьших привилегий:

| Роль | Описание | Доверенность |
|------|----------|--------------|
| **Гость** | Неавторизованный посетитель сайта | Минимальная |
| **Клиент** | Зарегистрированный пользователь, бронирующий наряды | Низкая |
| **Менеджер** | Сотрудник салона: оформляет выдачу, фиксирует дефекты, принимает залоги | Средняя |
| **Администратор** | Управляет персоналом, каталогом и настройками системы | Высокая |

## 4. Реализация в коде

Матрица будет реализована через:
1. **Декораторы Flask-Login** (`@login_required`) — проверка авторизации
2. **Собственные декораторы ролей** (`@role_required('manager')`) — проверка прав
3. **Проверки на уровне ORM** — менеджер видит только свои операции

---

## 5. Обоснование ограничений (для пояснительной записки)

1. **Клиент не видит чужие записи** — защита персональных данных (152-ФЗ)
2. **Менеджер не удаляет дефекты и залоги** — защита от мошенничества и ошибок
3. **Только Администратор управляет персоналом** — защита от несанкционированного создания учеток
4. **Гость не видит личные данные** — принцип минимальных привилегий
